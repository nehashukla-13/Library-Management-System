# Library Management System

## About the Project

This project is a mini Library Management System developed in Java using Object-Oriented Programming (OOP) concepts.

The system allows users to manage books and library users, issue books, and return books.

## Features

- Add new books
- Add new users
- Display all books
- Display all users
- Issue a book to a user
- Return a book
- Check book availability
- Interactive menu using user input

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner

## OOP Concepts Used

- **Encapsulation:** Private fields with public methods
- **Abstraction:** Classes are used to represent books, users, and the library
- **Inheritance:** Not required for this mini project
- **Polymorphism:** The project is structured using separate classes and objects
